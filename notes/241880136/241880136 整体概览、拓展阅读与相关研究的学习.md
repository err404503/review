## 一、该论文解决了什么问题

事先不知道集合大小的条件下，设计动态近似成员查询数据结构。
该数据结构需要支持：
- 输入：以在线方式逐个插入，假阳性率上界 $\epsilon$
- 输出：一个数据结构，支持插入和查询
- 要求：
  - 无假阴性
  - 假阳性率 $\le \varepsilon$
在此基础上实现趋近理论下限的时空复杂度。

已有方案的问题：
当 $n$ 已知的最优构造已被证明存在且充分研究。但当 $n$ 未知时，已有方案的空间大多为 $\Omega(n\log n)$ 位，非常差。

本文所实现的空间复杂度结论：
- 下界：$(1-o(1))n\log(1/\varepsilon) + \Omega(n\log\log n)$ 位
- 上界：$(1+o(1))n\log(1/\varepsilon) + O(n\log\log n)$ 位（基础构造），这与下界匹配

## 二、该问题为什么重要

本文及参考文献提到或搜索获得的数据指出，近似成员查询在以下场景中广泛使用，且这些场景中集合大小 $n$ 通常无法提前准确预知，但同时需要保持优越的空间占用和假阳性率，甚至还要支持删除等：

1. 网络流量监控与包路由：路由器需要对流经的数据包按"流"（flow，由源/目的 IP + 端口标识）进行去重、计数、路由。一个时间段内有多少条不同的流是完全不可预测的。

若 Bloom Filter 容量固定，要么在低负载时浪费 SRAM，要么在高负载时假阳性率失控，导致错误的路由决策。

2. 日志结构合并树（LSM-tree）的键值存储（来自 [BM03]，现代 NoSQL 数据库的核心技术）

LSM-tree（如 LevelDB、RocksDB、Cassandra）在每层 SSTable 上使用 Bloom Filter 来避免不必要的磁盘查找。写入量由应用程序负载决定，各层 SSTable 的大小随 compaction 策略动态变化。提前为该层分配固定容量的 Bloom Filter 意味着要么浪费内存，要么在数据增长后需要重建整个过滤器。

3. 分布式系统中的集合调和与数据同步（来自 [BM03] ）

分布式节点间交换键集差异时，通常用 Bloom Filter 压缩传输。节点间数据分布不均匀，某节点在某时刻持有的键数量无法提前知道。用固定容量的 Bloom Filter，发送方需低效地估算容量或多次往返。

4. 网络安全：入侵检测与病毒扫描（来自 [BM03] ）

入侵检测系统将已知攻击签名存入 Bloom Filter，在线匹配每个入站包。攻击签名库持续增长（新 CVE、变种），且增长速率完全不可预测。

5. 生物信息学：k-mer 计数与序列组装（来自搜索）

基因组组装中，需要判断某个 k-mer 是否在已测序的 reads 中出现过。测序深度不均匀，k-mer 总数无法提前确定。

6. 网页缓存与内容分发网络（CDN）（来自 [BM03]）

缓存代理服务器用 Bloom Filter 记录已缓存 URL 的摘要，用于快速判断是否命中。URL 集合的大小随用户请求动态变化，总有新的冷门 URL 出现，总量难以提前估计。该结构甚至还要求支持缓存过期时的删除。

## 三、相关研究

### 论文提到的相关研究

1. Bloom Filter

位数组 + k 个哈希函数，假阳性率 $\le \varepsilon$，空间 $1.44n\log(1/\varepsilon)$。不支持删除。

2. Counting Bloom Filter

将每个 bit 替换为计数器，支持删除。代价是空间增大 $\Omega(\log\log n)$ 因子。Cohen & Matias [CM03] 将额外开销降至 $O(n)$ 位。

→ 在正文中：论文拒绝了这个思路，因为在构造 2 中早期元素展开成大量签名，无法确定该删哪个，转而采用主辅字典方案支持删除。

3. 基于字典的近似成员查询

用通用哈希 $h: U\to[n/\varepsilon]$ 将元素映射到较短的域，再将 $h(S)$ 存入紧凑字典。空间可达 $(1+o(1))n\log(1/\varepsilon)$。

→ 在正文中：这是上界构造的基础。构造 1 的每个 $B_i$ 是此技术的实例，哈希到 $[2^i/\epsilon_i]$ 再用 RR03 字典存 $h(S_i)$。构造 2 的 $D_i$ 是此技术的变体实例，用成对独立哈希 $h_i(x)$ 替代通用哈希，并加入了 $g_i$ 辅助标签。

4. 在线与离线空间分离

证明：在已知 $n$ 但允许动态更新的设定下，必须有 $\Omega(n/\log(1/\varepsilon))$ 的额外空间开销，即使查询只在所有插入结束后才进行。

→ 在正文中：以该技术为背景，论文 §3 给出了未知 $n$ 的下界（$\Omega(n\log\log n)$）。

5. 动态完美哈希与检索

证明：在在线设定下维护动态完美哈希需要 $\Theta(n\log\log n)$ 空间，还需要已知 $n$。

→ 在正文中：虽然本文的哈希不是完美哈希，但是它可能启发了论文所论述下界中 $\Omega(n\log\log n)$ 项的存在性。

注意：本条如上大多是我的推测，从原文里获得的线索比较少，推测也可能是错误的。

### 论文未提到的相关研究

1. Cuckoo Filter

课件 Hashing.pdf 的 Cuckoo Hashing 是 Cuckoo Filter 的底层技术。Cuckoo Filter 将 Cuckoo Hashing 应用于近似成员查询：每个元素 $x$ 存一个 $f$-bit 指纹 $\text{fp}(x)$，通过 Cuckoo Hashing 将指纹插入哈希表的两个候选桶之一，查询时检查两个候选桶是否含目标指纹。需要已知容量，支持删除，空间约为 $1.05\times$ 信息论下界。

### 该论文发表后的新相关研究

1. Aleph Filter: To Infinity in Constant Time（Dayan, Bercea, Pagh, PVLDB 2024）

研究对象：可无限扩展的近似成员过滤器。
此前未解决：已有扩展型过滤器在扩展时，查询/删除性能、内存、假阳性率至少有一项会性能变差，无法无限扩展。
主要结论：Aleph Filter 无论数据增长多少，所有操作均为常数时间。且若预知增长上限，内存与假阳性率可匹敌静态过滤器。
方法：基于 Quotient Filter + InfiniFilter。每次扩展牺牲 1 bit 指纹获取额外地址位；复制空条目到两候选槽以支持单表 O(1) 查询；用墓碑+后台清除处理删除的重复副本。
与本文的关系：直接研究同一个问题。Aleph 的 Widening 和 Predictive 模式均达到该下界。

2. Resizable Retrieval（Kuszmaul, Putterman, Xu, Zhou, Zhou, 2026）

研究对象：可伸缩的动态检索结构，编码键→值映射，空间随当前集合大小 $n$ 参数化。
此前未解决：Demaine et al. 2006 的开放问题，能否把检索结构的空间上界从预设容量 $N$ 替换为当前实际大小 $n$。
主要结论：可以，并证明了匹配的空间-时间开销下界。作为推论，进一步给出动态过滤器的新构造。
方法：延长本文论文中的"碰撞风险分摊"技术，引入 midyard 辅助结构解决收缩时的碰撞，去摊销化达到最坏情况 $O(1)$。
与本文的关系：使用了本文论文的碰撞分摊技术。midyard 与构造 2 的桶化有一定相似。

3. Dynamic "Succincter"（Li, Liang, Yu, Zhou, FOCS 2023）

研究对象：动态 aB-tree 的紧凑编码，将 Pǎtraşcu 2008 的静态 2 bit 冗余成果动态化。
此前未解决：静态 aB-tree 需 2 bit 冗余，但动态化（支持插入删除）同时保持亚线性冗余此前未做到。
主要结论：动态 aB-tree 仅需 3 bit 冗余；作为应用构造了动态 FID，更新/查询时间最优（$O(\log n/\log\log n)$），冗余 $o(n/\log n)$。
方法：每个节点内用局部静态 Succincter 编码，全局通过 B-tree 维护。
与本文的关系：概念类比。论文仅将其列为紧凑字典/过滤器文献之一。它的贡献是降低底层字典的冗余（从 RR03 的 $o(n)$ 到 $O(n/2^{\log^{0.199}n})$）。

## 四、解决了该问题该论文提出了什么技术

论文给出了两个上界构造和一个下界构造。

### 下界构造（§3）

思路：若存在一个空间极小的近似数据结构，则可以用它来编码序列本身。编码长度不可能短于信息论下界，据此反推出空间下界。

步骤（直接摘自 241880161 的笔记）：

1. 随机结构 → 马尔可夫不等式（引理 3.2）→ 固定 $r^*$ 转为确定性结构
2. 对插入序列指数分段 $C_i, S_i$ → 抽屉原理（引理 3.3）：单段超集增量可控
3. 均匀采样 + 切尔诺夫界（引理 3.4）：绝大多数分段重叠元素数量可控
4. 构造四段无损编码 → 信息论编码下界建立矛盾不等式
5. 化简得到单段 $b_i$ 下界 → 结合 $c_i, n_i$ 等比关系证明定理 3.1
6. 代入两组参数：$\alpha = 1$ 时退化到已知 $n$ 的经典下界（自洽验证）；$\alpha = 1/\sqrt{n}, \gamma = 2^{(\log n)^\eta}$ 时导出主定理 1.1，总空间下界 $(1-o(1))n\log(1/\epsilon) + \Omega(n\log\log n)$

### 上界构造一（§4）

思路：既然不知道总共要存多少元素，那就每当当前这层满了就开容量翻倍的新一层。每个子序列假阳性率为 $\epsilon_i = \Theta(\epsilon/i^2)$ 依次递减，使得联合的假阳性率收敛。

步骤（概括自 241880136 的构造 1 学习笔记）：

1. 插入流按 $2^i$ 分块 → 为第 $i$ 块分配并初始化 $B_i$（容量 $2^i$，假阳性率 $\Theta(\epsilon/i^2)$）→ 共约 $\log n$ 个 $B_i$
2. 插入时判定元素属于哪个 $B_i$，直接插入该 $B_i$；若为第一项则先初始化该 $B_i$
3. 查询时遍历所有已有的 $B_1 \dots B_k$，任一返回 Yes 则 Yes
4. 假阳性率：联合界 $\sum \epsilon_i = \Theta(\epsilon\pi^2/6) \approx \epsilon$
5. 空间：RR03 字典存 $2^i$ 个元素 → 每 $B_i$ 空间 $(1+o(1))2^i\log(1/\epsilon_i)$ → 总空间 $(1+o(1))n\log(1/\epsilon) + O(n\log\log n)$
6. 时间：查询 $O(\log n)$（遍历所有 $B_i$），插入摊还 $O(1)$

### 上界构造二（§5）

思路：任意时刻只维护一个动态字典，逐步加长签名。元素的签名被选择性地展开。桶化控制过渡时的双倍空间开销。

步骤（概括自 241880136 的构造 2 学习笔记）：

1. 从成对独立族采样 $h:U\to\{0,1\}^\ell$（$\ell \ge \lceil\log(1/\epsilon)\rceil + \log u + 2$）→ 根据阶段 $i$ 截取前缀 $h_i$ 和标签 $g_i$
2. 插入 Mode 1（普通）：将 $(h_i(x), g_i(x))$ 存入当前 $D_i$
3. 插入 Mode 2（每层首个元素）：初始化新 $D_i$（容量 $2^{i+2}$）→ 迁移 $D_{i-1}$ 所有条目（$\alpha_1 \neq \bot$ 则延长 1 位，$\alpha_1 = \bot$ 则一起插入 $y0,y1$）→ 释放 $D_{i-1}$ → 按 Mode 1 插入
4. 查询时以 $h_i(x)$ 为键查当前 $D_i$，命中则 Yes
5. 容量及正确性：$D_i$ 条目数 $\le 2^{i+2}$（早期子序列每条贡献 $2^{i-j-r}$ / 近期子序列每条贡献 $1$）
6. 假阳性率：成对独立性 → 碰撞概率 $2^{i+2} \cdot 2^{-\ell_i} \le \epsilon$；加字典失败概率 $u^{-c}$ → $\le \epsilon + u^{-c}$
7. 空间：RR03 字典存 $n$ 个 $\ell_i$ 位签名 → $\log(2^{\ell_i}/2^i) \approx \log(1/\epsilon)$ → $(1+o(1))n\log(1/\epsilon) + O(n\log\log n)$
8. 失败处理：分组 $u^\delta$ 元素到一个字典（联合界控失败概率 $\le u^{-c}$）
9. 桶化：$u^{\delta/2}$ 个桶 + 字交错存储 → 过渡仅在一桶发生 → 空间代价降至单桶
10. 可选去摊销化，分摊 $D_i$ 初始化工作 → 插入最坏 $O(1)$。
11. 可选删除支持，主辅字典 → 辅字典存储与既有假阳性冲突元素精确值。

## 五、该技术背后的直觉是什么

### 下界的直觉（§1.3）

近似成员结构维护的是一个超集 $\hat{S}$，插入一个元素后 $\hat{S}$ 必须变成更大的 $\hat{S}'$。论文发现 $\hat{S}'$ 一般显著地比 $\hat{S}$ 大。若 $\hat{S}'\setminus\hat{S}$ 足够小，就可以将序列 $S'$ 压缩到信息论下界以下。

### 上界构造 1 的直觉

既然不知道总共要存多少元素，那就每当当前这层满了，就开容量翻倍的新一层。每一块越来越精确，这样总误差就可以控制在常数倍 $\epsilon$ 附近。

### 上界构造 2 的直觉

构造 1 的查询需要对所有数据结构逐一查太慢。构造 2 的解决方式：只维护一个字典，但它的精确程度逐步提升。旧的信息通过翻倍模糊处理保证正确性。

## 六、该技术有什么非凡之处/厉害之处

1. 论文首次从下界角度说明了"自适应扩容"是有固有代价的，且这个代价是 $\Omega(n\log\log n)$。

2. 本文的两种构造空间均为 $(1+o(1))n\log(1/\varepsilon) + O(n\log\log n)$，与下界 $(1-o(1))n\log(1/\varepsilon) + \Omega(n\log\log n)$ 仅差低阶项。

3. 构造 2 同时达到了多个最优：空间逼近下界 + 查询常数时间 + 插入摊还常数时间，并可以自由选择插入摊还还是桶化优化总空间。

4. 在构造 2 中，用 $\log\log u$ 位标签精确控制每个早期元素的展开次数，既控制到了相比于只存签名略多的空间占用，又保证了迁移和查询正确性。
